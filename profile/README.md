# PostgreSQL extensions for Windows

pgextwin is an independent community project that publishes **unofficial Windows x64 binaries** for selected PostgreSQL extensions.

Use the [English extension catalog](https://pgextwin.github.io/website/en/) to find available packages and PostgreSQL versions, or [browse published Releases](https://github.com/orgs/pgextwin/repositories). The project currently covers **17 extensions**; a new upstream version is available to download only after its own Release is published.

Choose the ZIP for your PostgreSQL major version and follow that extension's installation instructions. Supported packages are available for selected PostgreSQL **14–18** versions. PostgreSQL 14 community support ends on **November 12, 2026**. Each Release provides SHA-256 checksums; additional verification materials depend on the Release.

Upstream extension authors maintain the functionality and documentation. pgextwin is not affiliated with or endorsed by PostgreSQL, EDB, or these upstream projects. The applicable license is included with each distribution.

# Windows向けPostgreSQL拡張機能

pgextwinは、PostgreSQL拡張機能の**非公式Windows x64バイナリ**を公開するコミュニティプロジェクトです。

[日本語の拡張機能カタログ](https://pgextwin.github.io/website/ja/)では、公開済みパッケージと対応するPostgreSQLを確認できます。対象は**17種類の拡張機能**です。新しい上流バージョンは、各拡張機能のReleaseが公開された後にダウンロードできます。

利用中のPostgreSQLメジャーバージョンに一致するZIPを選び、各拡張機能のREADMEに従って導入してください。PostgreSQL **14〜18**向けのパッケージがあります。PostgreSQL 14のコミュニティサポートは**2026年11月12日**に終了します。各ReleaseにはSHA-256チェックサムが付属し、そのほかの検証資料はReleaseによって異なります。

拡張機能の機能・使い方は上流プロジェクトが案内しています。pgextwinはPostgreSQL、EDB、各拡張機能の開発元とは独立しており、公式の承認を受けた配布ではありません。ライセンスは配布物に同梱されています。
